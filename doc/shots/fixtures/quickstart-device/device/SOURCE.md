# Fixture device

Shown in the workspace as a USB mass storage device (`Shoot/fixtureDevice`, `CShotFixture`).

## Garmin/GarminDevice.xml

Written by hand for a GPSMAP 64s, which connects as USB mass storage and records GPX (owner's manual). Holds only the
data types `CDeviceGarmin` reads for GPX and photos; the part number `006-B0000-00` is a placeholder.

## Garmin/GPX/Track_2025-06-14 101530.gpx

A recording as the device saves it: the track of `../../default/GPX/Example.gpx` with its points' position, elevation
and time only, moved to 14 June 2025. File and track name follow the date pattern guessed for the device. Author
fuzzybear, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
