#############################################################
#         QMapShack for Windows dependencies                #
#############################################################
This installation of QMapShack for Windows (short: QMS) 
has been build with Visual Studio 2022 as 64bit application.

If you want to build QMS on your own, have a look at
https://github.com/Maproom/qmapshack/wiki/BuildWindowsVisualStudio

The QMS source code is available at https://github.com/Maproom/qmapshack

Dependencies
============
QMS depends on the 3rd party software listed below:

 1.) Microsoft Visual C++ 2022 Redistributable Package
     The installer vc_redist.x64.exe (approx. 18 MB size) as downloaded from
     https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
     is already contained in the QMS Installer package and will be executed if selected by the user.

     Note: Those runtime libraries may already be contained in Windows 10/11 installations.

 2.) Qt6 runtime libraries
     The Qt libraries are deployed in the QMS installation directory.
     Qt is used according the GPLv3 open source License
     See https://www.qt.io/download-open-sourcei
     and https://www.gnu.org/licenses/gpl-3.0.html

 3.) GDAL library, source at https://gdal.org
     MSVC 2022 library, header and binary precompiled files are contained
     in GDAL release available at https://www.gisinternals.com/release.php

 4.) PROJ library and data, source at https://proj.org
     MSVC 2022 library, header and precompiled binary files are contained
     in GDAL release available at https://www.gisinternals.com/release.php

 5.) Icon for GDAL shell in the Windows start menu
     GDAL package's gdalicon.png has been converted to gdalicon.ico.

 6.) Routino library and translations, source at https://www.routino.org
     This QMapShack installation uses a Routino library
     which was precompiled with mingw-w64 to reduce porting efforts.

 7.) mingw-w64 compiler, https://www.mingw-w64.org
     The mingw-w64 compiler is used to compile the Routino library and build the Routino binaries.
     The resulting binaries depend on mingw-w64 runtime libraries libwinpthread-1.dll and zlib1.dll
     which are also included in this installation.

 8.) MySql/MariaDB
     For MySql/MariaDB support, Qt's sqldrivers plugin qsqlmysql.dll
     as well as dependent runtime library libmysql.dll are required.
     As Qt does not provide these binaries itself, a MSVC 2022 precompiled driver bundle suitable
     to Qt version can be downloaded at https://github.com/thecodemonkey86/qt_mysql_driver/releases
     and is included in this installation.

 9.) libjpeg, source at https://www.ijg.org
     The libjpeg.lib and header files are needed to compile the helper program qmt_map2jnx.exe.
     MSVC 2022 library, header and precompiled binary files are contained
     in GDAL release available at https://www.gisinternals.com/release.php

10.) zlib, source at https://zlib.net
     zlib is used to build cURL and GDAL with support for additional formats.
     MSVC 2022 library, header and precompiled binary files are contained
     in GDAL release available at https://www.gisinternals.com/release.php

11.) cURL, source at https://curl.haxx.se
     cURL is used to build GDAL with support for additional formats.
     MSVC 2022 library, header and precompiled binary files are contained
     in GDAL release available at https://www.gisinternals.com/release.php

12.) sqlite, source at https://www.sqlite.org/download.html
     MSVC 2022 library, header and precompiled binary files are contained
     in GDAL release available at https://www.gisinternals.com/release.php
